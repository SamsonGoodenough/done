# Done

**Watched it? Played that? Done ✅**

Done is a self-hosted, invite-only app for tracking everything you've watched, played, and read: movies, TV shows, games, and books, all in one place. Rate it (0-5 stars, half stars allowed), write a review, flag spoilers, mark favourites, log rewatches, and keep a backlog of what's next.

This repo is currently in the **planning phase**. No code yet, see [`docs/planning/`](docs/planning/README.md) for the full plan: features, data model, database choice, roles/permissions, external API integrations, architecture, and roadmap.
